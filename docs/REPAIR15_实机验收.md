# REPAIR15 实机验收（此环境尚未执行）

目标：Skyrim 1.6.1170.0 / SKSE 2.2.6。先复制测试存档和对应 SKSE co-save，保留原安装包可回退。

## 构建与身份

1. 合并完整源码并保留已有依赖/设置/缓存；运行 VERIFY_LATEST.bat、BUILD.bat
2. 日志和构建标识应为 FC-0.5.4-REPAIR15-20261001-K，F8标题为0.5.4暂停跟随修复15
3. 安装实际编译生成的MO2运行ZIP，保持FreedomControlRuntime.esp启用；源码ZIP本身没有DLL
4. 此身份检查只是排除测试对象混淆，不预设之前的问题是旧DLL导致

## F8完整暂停

- 找一名正在走动的NPC，或观察战斗/飞行中的投射物；按F8后持续观察位置、动作和游戏时间，应停止游戏模拟
- 保持F8打开，数字行/数字小键盘/中文输入/粘贴/滚轮/点击和切换页面仍可用；资源改动正常提交
- 即使旧INI为PauseWorld=0、旧存档pauseMenu=false，也不能把F8暂停关闭
- Alt-Tab离开再回来：F8仍在、原生暂停仍持有；此前按键不应黏住或误触其他模组
- 连续开关10次；按住移动键打开，在F8里释放，再关闭，确认没有持续移动/攻击等残留
- 普通编辑/批量操作先完成再关闭；传送、自动生成、原生菜单和休息在本工具原生暂停确实退出后执行
- 叠加原版暂停菜单，关闭F8后原菜单仍暂停；关闭原菜单后游戏恢复。打开F8前已有的freezeTime状态不能被强制清零
- 打开和关闭过渡时读档、退出主菜单；加载后不能遗留本工具的暂停菜单或旧的待执行动作
- 查看NativePause15日志：需要原生菜单on-stack、pause flag和full-pause readback确认，不能只凭freezeTime布尔值或面板文字判断

## 实际跟随（关闭F8后观察）

F8本来就会暂停NPC；读回包ID不等于角色已经走动。分别用普通人形、无E入口的地面生物及此前能跟随/不能跟随的两个具体模板测试。

1. 招募现有角色和自动生成入队分别测试；关闭F8后走出跟随停止距离，观察实际走跑/转弯/避障
2. 别名未就绪/启动延迟时，登记不能被直接拒绝；正常强接管模式应可使用本工具无条件引用后备包
3. 当前包已是自有后备程序时，不能每两秒重新清AI路径；角色应有持续执行程序的时间
4. 改变距离档位；已有别名和从后备恢复到别名两条路径都应重新选择一次，之后保持稳定。冻结/等待期间修改，继续后生效
5. 等待不追随；全局冻结优先，单体继续不能绕过冻结。解冻/继续后跟随恢复
6. 正常敌人战斗不被跟随包循环打断；战斗后恢复跟随。跨Cell战斗仍不能被随意拉走
7. 跨门/跨区域、楼梯和障碍；长时间无进展可用原有有限纠偏，不允许每帧传送取代自然移动
8. 纯水生不拉上陆地，步行生物不拉进深水，飞行/龙不强吸地面；龙别名恢复后回到原环绕程序
9. 生成尚未完全加载时解散/移除：不能被出生队列重新招募、写属性或改位置
10. 保存、退出、读档后已有成员恢复；解散恢复本工具记录的原状态，其他同基础模板的未招募角色不应改变
