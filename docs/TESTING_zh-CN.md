# 0.5.0 实机验收清单

本环境未执行下列游戏测试；请将它们与docs/validation11的主机测试区分。

1. 日志首行0.5.0 Kernel11，F8题头自由内核11，右侧已启用新版Runtime.esp。F8关闭后时间和控制恢复。
2. 自由内核默认“原生拦截：已安装”；赏金增加/监禁/罚款计数随原生尝试变化。守卫正常手动对话仍可进行，普通敌人和军团仍可战斗。对照单项关闭恢复原生处理。
3. 需要钥匙的普通配对门，接管并使用后能否进入；容器和床归属即时刷新。脚本门/无配对目标观察明确失败提示，而非伪造成功。自行坐椅子前关闭强自由的家具脱离。
4. 普通玩家操作禁用时守护是否恢复，F8和对话中是否仍无输入透传；临时放行60秒是否允许剧情控制；不同存档的设置是否隔离。
5. 任务中心直接输入任务名即可见ID/来源；停止、追踪、目标状态/文字在当前游戏读回。拒接后重启指定任务会被停止，不误伤其他任务。
6. 自建一条手动目标任务，保存并开始，关闭F8打开J查看；完成/暂停/继续/重置/同名任务选择、读档文本/进度保留、槽位删除复用。
7. 收集1件物品、到达记录位置、击败指定实例判定；删除而非杀死NPC不应虚报击杀目标完成。
8. 回归：先生成2名士兵随行/进出门/战斗，DC目录搜索、资源/跑速实时、净域军团保护保持此前行为。

强自由会主动阻止场景和坐姿，不是其发生故障。停止原版剧情任务、跳阶段、彻底删除NPC的既有后果不会被关闭规则自动撤销。资料不足时保留具体目标ID与当次日志，不用反复改MO2排序猜测。
