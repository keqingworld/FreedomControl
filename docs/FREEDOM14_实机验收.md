# Freedom14 游戏验收清单（尚未执行）

目标 Skyrim 1.6.1170.0，匹配 SKSE，MO2只启用一份插件。先复制测试存档与SKSE co-save，不在唯一主线存档上试验。

## 构建/升级

1. 保留现有依赖、build-settings.json、build、commonlib.lock.txt。运行 VERIFY_LATEST.bat，标识为 FC-0.5.3-FREEDOM14-20261001-J。
2. BUILD.bat 必须完成真正 FreedomControl.dll 编译和链接、七个便携测试、内容指纹/打包校验。安装 dist/FreedomControl-0.5.3-FREEDOM14-MO2.zip；不能直接安装源码ZIP。
3. 游戏日志第一行0.5.3 Freedom14，题头“0.5.3 | 全局自由14”。确认 CommonLib版本/运行时1.6.1170匹配、运行ESP启用。

## 全局玩家自由

- 自由内核默认“全局玩家自由”开启。守卫/普通NPC主动强制对话应被释放；计数增加，日志给出当前说话者/Scene ID。记录是否出现残留视角或菜单。
- 对相同NPC主动按原E、改绑激活键、手柄激活分别发起对话。完整选择选项，长时间对话，关闭后再开，确认主动会话保留，输入未穿透。
- 激活NPC A，NPC B同时强制搭话，不应凭A的意图放行B。仅瞄准NPC、不按激活不构成许可。
- 正常NPC路过问候、附近NPC互相对话，且未占用玩家时，不应被无差别中断。
- 脚本禁用玩家移动/转向/战斗/施法、AI Driven、Restrained，检查恢复；战斗正常受伤、死亡、麻痹、读档、暂停不应被误改。
- 按“允许剧情接管60秒”后剧情可以取得控制；到期恢复，点“立即恢复”提前恢复。主动接受门/机关引出的剧情也用临时放行。
- 关闭全局自由应停止其后续干预；旧的各控制细项仍按设置工作。读档/新游戏不沿用上个场景的临时交互许可。
- F8、物品/魔法/地图、容器/交易、书本、消息框、暂停与主菜单测试；不应因为按激活对应物理键就误给后台NPC交互许可。
- 某强制剧情被中断后，退出控制是否完整、任务是否等待。该项可能有剧情后果，不能以“没有全局StopQuest”推断完全无后果。
- 不用获得物品提示声/文字是否消失当作通过标准：本版没有全局物品变化撤销。

## 生物跟随

每种至少测三只：普通士兵、无对话入口的地面DemonicCreatures、飞行生物、纯水生、龙、大体型生物、原本有脚本包的生物。记录可跟随与不可跟随模板，不假定同一模组全部相同。

1. 自动入队，观察“模型/AI就绪”和“跟随包已读回”分别计数。15秒仍未确认时应显示待确认并持续维护，不说成功、不自动删除。
2. 平地移动、转弯、障碍物、楼梯、室内外传送门、跨Cell、战斗后回到玩家。包读回成功还要看实际移动/动画。
3. 有生物脚本在生成后延迟写AI/阵营/程序时，观察限频重试是否接管，而非每帧打断或刷日志。
4. 等待期间不追随，继续命令恢复；冻结优先；真正敌人战斗不应被跟随包反复取消。
5. 模型加载期间解除控制，不能被生成队列再次招募。取消生成后已有实例仍可正常管理。
6. 解散恢复原有记录的AI/队友/阵营/控制状态，退出本工具临时程序；其他同模板NPC没有被改种族、共享包或阵营。
7. 纯水生玩家在陆地不应被反复拖上岸；玩家入水再测。飞行/龙不得按地面寻路点硬落地；地面生物不会追着空中玩家落在半空。
8. 无可用移动动画/不可移动种族应显示真实限制；不接受“所有模组生物肯定能走路”的结论。
9. 存档、退出、加载，别名重新协调一次；旧军团、资源设置、自建任务、房屋、清理保护仍保留。

## F8热键隔离

- 把0—9设为另一个模组的菜单热键；F8资源输入框逐个输入、删除、粘贴，不能打开该模组菜单。F8关闭后重新按下仍正常触发。
- 测试按下触发、抬键触发及按住触发；输入过程中关闭F8、释放键，再重新按。不要把菜单中残余抬键当新操作。
- 打开F8前按住W/A/S/D、Shift、Ctrl，菜单中释放后关闭；检查没有持续移动、潜行、冲刺或第三方按键状态卡住。
- 鼠标滚轮、手柄摇杆/按钮、Alt-Tab切出切回也要回归；输入阻断是整个事件批次。
- 如果特定模组仍触发，记录其实际名称/版本/键位；独立物理按键轮询或更靠前的输入钩子不在当前阻断保证内。
