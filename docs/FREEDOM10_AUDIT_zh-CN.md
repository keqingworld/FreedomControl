# 自由版10 · 实现分析与证据范围

构建：FC-0.4.0-FREEDOM10-20260925-F。

## 1. 为什么这次换独立运行插件

旧实现登记成员之后，主要依赖运行时拼装跟随包与重申命令。登记、调用 EvaluatePackage、甚至模拟测试通过，都不能证明真实引擎在执行完整跟随程序。用户反馈“原地站着 / 按原路线走”表明旧链路未达到实机要求；没有当次实际 NPC 当前包日志，所以不能把唯一根因假定为某个冲突 Mod。

新实现不再创建不完整的临时跟随包，而是新增原创 FreedomControlRuntime.esp：一个优先级127任务、512个引用别名，26个含程序模板/输入/条件的包。别名填充后读取实际引用，再读取 NPC 当前执行包是否来自这个运行插件；界面区分“已登记”“别名已绑定”“包在执行”。原版随从任务不被占用，不需要 SexLab。

普通地面包有8档距离和3个错开距离；飞行龙另用环绕模板。Alias/Package二进制结构参考研究包中普通跟随实现以及xEdit字段定义，实际文件由本项目生成器重新编写，没有复制第三方脚本或整个记录。

## 2. 自然跟随不是逐帧传送

NPC正常走跑、寻路、战斗由引擎完成。选中目标的移动限制 / 场景与家具占用按设置释放；原阵营隔离为可选，只保存并修改具体实例。战斗进行时不持续用跟随更新取消战斗。跟随控制重申限频；持续无进展默认12秒后纠偏，跨区或超距可召回。脱困判断容差与行为包的实际停止距离一致，避免已在正常跟随距离内却不断被传送。

原生引擎可能仍拒绝某些强制场景、导航或飞行操作，本环境没有实机验证。因此“独立”指独立任务/别名/状态管理，不是保证无需引擎导航。

## 3. 新生成不是把已有 NPC 填进一个列表

军团新增三个明确的生成入口：自动挑士兵模板、使用生成器模板、使用当前NPC的基础模板。创建位置由玩家处锚点记录，但生成调用使用当前玩家引用；随后启用、设置位置/AI/可见性，等模型和AI过程加载后才计入“就绪”。每帧最多创建2个，15秒无模型/AI会标记未通过，不能只因为拿到RefID就说士兵已在身边。

生成的引用与基础ID分开管理；传送锚点只做定位。关闭菜单并恢复模拟之后才开始生成，以免面板暂停阻止出生流程。可以取消未执行部分，已生成的引用仍在实例列表中。随机敌人仅修改新实例的敌对，不把原地图角色批量变敌人。

## 4. 从提供的研究包提取了什么

读取 NPC_ / RACE / 主文件映射等非动画基础信息。与生成目录相关、实际有 NPC_ 的四个插件：CreatureSummoner.esp 160条；DemonicCreatures.esp 736条；MoreNastyCritters.esp 197条；SLDragons.esp 6条。总共1099条记录，按定义插件和本地ID去重后1097个键；DC标签736个未漏。

目录并非SLAL动画目录，也不以皮肤/种族ID冒充可生成NPC。当前游戏启用哪些插件需要运行时解析，本上传包没有完整活动加载顺序及所有基础主文件，因此静态1097不是“当前实际可用1097”或“所有已安装模组的全部生物”。界面显示解析数，未提供/未启用者不伪造ID。“同种族扩展”可额外匹配加载NPC，但不声称动画兼容。

本包只携带提取的基础ID/命名/种族映射等目录信息以及本项目原创运行记录；未附带第三方ESP、脚本、模型、纹理或动画。普通随从系统和快速生成器彼此独立，也不触发第三方动画系统。

## 5. 旅行自由的准确含义

F8的对象/书签/地图标记传送不走原版快速旅行许可，门使用ExtraTeleport链接与目的位置/朝向。没有把门模型坐标当落点。独立入口可绕开敌人附近、负重等旅行许可条件，但目的地正常加载、相关任务加载脚本仍存在。

仅“解除脚本快速旅行禁用标记”不会移除原版所有地图/E键检查。未知模组的脚本门、剧情控制、无传送链接闸门不自动解决；释放玩家控制功能不偷偷停止全游戏任务。本版不声称“取消Skyrim所有强制机制”。

## 6. keqing范围与全局清理

新增原创小能力，原生施法事件将清理请求排队。无伤害/召唤特效依赖，面板也可直接施放。半径清理只在同一室内Cell或相同室外世界空间内；始终排除玩家，军团保护可选。包括待入队的新出生实例，避免部队尚未绑上别名就被领域删掉。

全局操作先在Form映射读锁下收集已有Actor引用ID，释放锁，再在主线程分帧操作；每条再次核对存档世代与基础ID。每帧最多64条/约4ms，停止可取消未执行部分。此处毫秒预算只限制每条操作之间，不是每个原生函数绝不超时的保证。

全局一次针对已有实例；持续模式监听新加载并定期检查当前处理角色。未实例化角色本来不存在可立即删除的运行引用，不伪报它们已被一帧删除。原NPC模板不删，避免直接摧毁生成池。移除同一引用抑制不会阻止所有脚本重新生成一个全新ID；持续领域能继续处理新加载实例。取消不复活已删除角色。

## 7. 验证与未验证

本环境实际编译/执行四组独立C++测试；实际新控制层cpp用明确的模拟引擎对象编译执行，84条断言；真实CMake打包56场景；身份/缓存14场景；新ESP/目录12项结构测试。菜单类与Engine头也做了桩环境语法编译。完整日志在validation10。

这些检查能发现调用链、边界、计数、别名分配、排队删除/取消、版本、打包及一部分C++问题，不能证明真实CommonLib ABI、Skyrim寻路/龙AI、ESP加载、资源模型、原版GUI/输入和任务兼容。此轮完整WindowsDLL没有在这里编译，运行插件也没有在游戏/xEdit/CreationKit实际加载。本包没有假冒编译好的DLL。
